# 📌 습습해 – 자동 습도 조절 이동식 가습기
## 프로젝트 개요
> 프로젝트명: 습습해 (자동 습도 조절 이동식 가습기)</br>
> 프로젝트 유형: 캡스톤 디자인 팀 프로젝트 (3인)</br>
> 소속: 동양미래대학교 정보통신공학과</br>
> 수상: 캡스톤 디자인 경진대회 최우수상

</br>

## 🛠 개발 환경 및 사용 기술
- Arduino
- 온습도 센서
- 초음파 센서
- 가습기 모듈
- BLE / 모터
</br>

## 📗 핵심 기능
1. 온습도 센서를 통해 실내 습도를 측정하고 습도에 따라 가습기 모듈 자동 On/Off
2. 초음파 센서를 활용해 주변 장애물을 감지하고 이동 방향 제어
3. 모터를 이용한 자동 이동 기능으로 사용 공간의 제약 최소화
4. 습도 조절과 자동 이동 기능을 결합해 사용자의 편의성 향상
</br>

## 👩🏻‍💻 담당 역할
1. 프로그래밍: 센서 입력값에 따른 가습기 모듈 및 모터 동작 제어 구현
2. 자료 조사: 제품 개발을 위한 관련 기술 및 부품 조사, 경쟁 제품 분석
3. 부품 구매: 프로젝트 구현에 필요한 부품 조사 및 구매
</br>
